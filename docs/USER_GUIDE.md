# 启圣之尘收益计算器 2.1

双击「GenshinDustCalculator-2.1.0-win64.exe」运行。Windows 64位；无需安装 Python 或 Qt，计算完全离线。

本修复版解决了「DLL load failed while importing QtCore」启动错误。打包环境已隔离其他工具的DLL，内置Qt配套Visual C++运行库，使用Windows自带的UCRT。已在当前Windows 10电脑上验证实际EXE启动、浅色／深色界面和两个样例计算。

2.1在概览顶部显示当前总评分、每条正权重属性的贡献、有效强化次数；计分属性和两条保底目标分开标注。小于0.01%的正概率不再显示成0.00%。
界面包括米白/淡金与深蓝/金色两套主题、圆角输入与分段保底按钮、数据卡片、可切换的收益图表，以及原版启圣之尘透明道具图标。点击右上角月亮/太阳图标切换主题。

## 快速使用

1. 程序启动先展示攻击杯样例的实际结果。点击右上角「新建圣遗物」可清空当前圣遗物和旧结果。
2. 选择部位，填写初始3／4词条；初始词条不知道可选自动推断，名称可不填。
3. 选择四条副属性类型，填满级面板数值。百分比填6.6即6.6%，固定值填整数，表格旁显示单位。
4. 每条独立设置权重。默认暴击率、暴伤为1，其余0。三条、四条有效都支持，权重可精确到0.001。
5. 保底目标必须选两条；有效但未选作保底的属性仍参与全部计算。
6. 选择本次保底2、3、4次，点击计算。可查看六种组合排名，或采用本档期望收益最高的组合。
7. 本次保底与计算按钮固定在左下方，左右内容区均可滚动。
8. 可选高级设置收起显示：强化次数、基础档位、主属性校验和祝圣之霜定义目标锁定。
9. 高级信息不知道可以全保留自动；强化次数不含基础出现一次。无需每次强化的完整历史。
10. 「粘贴属性文字」可一次填写四条，例如：暴击率+6.6%、暴击伤害+20.2%、防御力+42、元素精通+23（每条一行）。
11. 「攻击杯示例」「花示例」载入原先两个截图；「样例对照」按当前权重比较这两件。
12. 保存/导入JSON配置；导出HTML报告时同时生成同名完整离散分布CSV。
13. 修改输入后旧结果会标记为待更新，并暂时禁止采用旧组合、导出旧报告；点击计算恢复。

### 换其他圣遗物，需要哪些信息？

| 信息 | 怎样填写 |
|---|---|
| 部位 | 花、羽、沙、杯、冠 |
| 初始词条数 | 3条或4条；不知道选自动推断 |
| 四条副属性 | 类型和+20当前数值，都必须填 |
| 权重 | 需要的设正数，不需要的设0；默认双暴各1 |
| 本次保底 | 两条目标，以及本次保底2／3／4次 |
| 可选信息 | 名称、追加强化次数、基础成长档位、主属性类型 |

例如，副属性为「暴击率6.6%、暴伤20.2%、防御力42、精通23」，就分别填6.6、20.2、42、23。
防御力42与防御力5.8%是不同的属性类型，须选对下拉框。
套装名称与主属性数值不参与副属性重塑评分，无需填写。

## 收益单位

一次平均成长 = 1个等效平均词条（权重1）。计分 S = Σ 权重×属性实际值/该属性一次成长均值。
暴击率均值3.305个百分点、暴伤均值6.605个百分点，因此相同权重表示一次平均成长价值相同。

计算时使用每一次成长的四个具体档位，绝不把随机成长替换为均值；均值仅用于评分单位。
显示的期望净增为 E[max(新分数－旧分数,0)]。游戏允许保留旧结果，资源仍消耗。
图表分箱只影响展示；内核使用有理数整数格点和完整离散概率分布。

## 结果应该怎样理解

- 变好概率：本次出现严格更高评分的概率，相等不计提升。
- 平均净提升：所有结果先择优保留，再求期望。
- 每枚尘收益：平均净提升除以本次尘消耗（花羽1，沙杯冠2）。
- 目标概率：最终净提升至少达到输入目标的概率；目标0时为100%。
- 成功时平均提升：在确实变好的前提下，通常增加多少。
- 合法范围：每种基础档位合法分解下的结果最小/最大值，不是置信区间。

## 未知初始档位

两个截图都不能唯一确定全部基础成长档位。程序枚举合法分解，同时显示：
1. 四档等概率、原始随机强化前提下的条件估计；
2. 全部合法分解对应的收益与提升概率范围。

若知道基础档位，可以指定后重算。已有历史重塑择优或筛选偏好时，条件估计的先验可能不完全匹配；范围仍可帮助判断。
程序不能仅凭满级截图还原真实初始值或每次强化先后。
自动初始三/四词条若同时可行，暂按两种模型等先验；应尽量根据强化次数选定。

## 机制与精度

采用社区研究的末尾补足保底模型；官方公开保底次数，但没有公开全部随机算法。
保留基础成长值，重抽强化落点和成长档位；普通阶段四条各25%，强制阶段所选两条各50%，四档各25%。
基础值保留与完整随机细节使用社区计算模型，不能称为官方公开的完整概率。
采用两位小数成长表及显示舍入，内部浮点舍入边界可能有微小差异。
本版直接选择本次保底档位，不自动跟踪账户6点进度，也不摊入攒保底期间的其他资源。
「祝圣之霜定义」锁定当前指定的两条目标；须填最初定义时选择的目标。
副词条评分不等于实际角色伤害，未加入暴击溢出、充能阈值、角色和队伍伤害模型。

## 校验与交付

11项模型测试通过：独立分布推导、两个截图、三/四有效词条、五次强化全有效且充能未选作保底、逐条贡献求和、零权重、档位约束、输入检查等。
4项文本录入校验通过；Qt界面检查通过：两套主题、新建清空、必填提示、高级字段折叠、文本粘贴、旧结果防误用、异步计算、最优组合、目标锁定、样例比较、图表切换、报告导出、最小窗口。
两个手算样例已按独立公式复核，见「two-artifacts.md」。
源码及测试在「GitHub Source code (zip)」，可继续修改或重新打包。
