# 充能权重100：截图结果核验

结论：在程序所采用的基础值保留、末尾补足两条目标保底、四成长档位等概率模型下，截图所有数值与独立枚举吻合。

## 核验输入

五星初始4词条的+20攻击杯，副属性依次为：充能18.1%、防御5.8%、暴伤20.2%、暴击率5.4%。
强化次数依次2、0、2、1。权重依次100、0、1、1，保底目标为暴伤和暴击率。
目标净增为1个加权评分单位。本次消耗2枚尘。

保底目标仍为双暴，保底越高，给高权重充能的强化机会越少。

## 单位和评分

S = 100×充能/5.505 + 暴伤/6.605 + 暴击率/3.305。
100表示一次平均充能成长的评分价值为一次平均暴击或暴伤成长的100倍。
所以5.408是加权评分净增，不能解释为实际多了5.408次强化。
程序先枚举满足面板舍入的合法两位小数表值，评分采用条件估计。
充能18.1对应表值18.14，暴击率5.4对应5.44，暴伤20.2对应20.20或20.21；
未声称仅凭截图还原了真实初始档位或游戏内部浮点值。

## 独立验证方法

独立脚本只用Python标准库，无需程序内核。
手工列出的基础暴伤和基础充能状态见「three-effective.md」。
令双暴合计命中次数K=max(Binomial(5,1/2),g)。
保底2时K=2/3/4/5的概率分别16/32、10/32、5/32、1/32。
双暴每次成长为暴伤或暴击率四档，共8种等概率结果。
未命中双暴时为充能四档或防御四档；防御权重0，因此有四个零贡献结果。
用整数计数分别卷积双暴与非双暴的成长，再合并所有合法基础/当前状态。
概率、评分比较和期望使用Fraction精确有理数，避免浮点阈值和分箱误差。
由此求P(新分数>旧分数)、E[max(新分数-旧分数,0)]及P(净增>=1)。

独立结果与engine.py对三组有效保底组合、三档保底的最大绝对误差为1.120e-11，不会影响截图展示精度。

## 按该权重比较保底目标

本次保底2时：
- 双暴目标：平均净提升5.408391，变好概率10.107687%。
- 充能＋暴伤：平均净提升10.308958，变好概率14.782058%。
- 充能＋暴击率：平均净提升10.308958，变好概率14.788845%。

后两种组合收益非常接近，微小差异来自成长表值和离散相等边界。
若目标为充能权重100，选充能加一条暴击属性的两种组合在本次保底2档均优于双暴。
若是祝圣之霜定义、目标已锁定的圣遗物，应使用其固定目标。

四档等概率、保留基础值和随机保底细节采用社区模型，官方没有公开全部随机算法。
