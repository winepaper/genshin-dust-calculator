# 攻击杯：三条有效属性，五次强化全部命中

副属性：充能18.1%、防御5.8%、暴伤20.2%、暴击率5.4%。
权重：充能、暴伤、暴击率各1，防御0；保底目标为双暴。
初始四条，强化次数依次2、0、2、1。

所有正权重属性都计分，充能未勾选为保底也计分。
权重与保底选择互相独立；换一组保底不会改变当前评分。

## 当前评分

S = 充能/5.505 + 暴伤/6.605 + 暴击率/3.305。
当前评分包含基础出现及五次强化；评分单位为等效平均词条。
按面板一位小数直接代入约7.980；程序采用满足面板舍入条件的合法两位小数表值。
充能18.1对应18.14，暴击率5.4对应5.44，暴伤20.2对应20.20或20.21。
基础档位不明时按合法状态的条件分布估计评分，并提供合法范围。
这一步不是声称已还原游戏真实内部数值。

当前评分条件估计：7.999844793；合法范围7.999466292～8.000980297。

元素充能效率 3.295（权重1） ＋ 暴击伤害 3.059（权重1） ＋ 暴击率 1.646（权重1）；不计分：防御力%（权重0）。

## 为什么五次没歪，仍有提升概率？

按有效强化次数衡量，已达5/5。但程序还计算每次成长的四档数值。
例如暴击率5.4对应基础2.72及一次强化2.72；重塑后这次强化有机会获得3.11、3.50或3.89。
同时重塑仍可能把强化分到防御，或获得较低档位，所以整体收益很小。

## 独立算术验收

manual_three_effective.py 不调用程序engine.py。
双暴命中次数K=max(Binomial(5,1/2),g)，双暴内各属性公平分配。
未命中双暴的强化在充能、防御之间公平分配。强化档位各25%。
原充能18.14的有序三份组合为(5.18,6.48,6.48)及(5.83,5.83,6.48)，各有3种排列；
所以基础充能为5.18、5.83、6.48的条件概率分别1/6、1/3、1/2。
基础暴伤联合状态沿用「two-artifacts.md」中手工列出的六种状态。
在各基础/当前状态下分别卷积双暴与充能四档分布，再求P(新评分>旧评分)及E[max(差值,0)]。
三档结果与程序在1e-11误差内一致。

采用原版模型假设：基础值保留，末尾补足两条目标保底，四档等概率。
它是社区概率模型，不代表官方公开了全部随机实现。
