# 只看充能：原始风险与择优收益复核

这里核对的是充能18.1%、防御5.8%、暴伤20.2%、暴击率5.4%的初始四词条攻击杯。
原有强化为充能2次、暴伤2次、暴击率1次。目标仍勾选双暴，本次保底2次。

## 用户直觉成立

绝大多数原始重塑结果会更差。软件显示的是坏结果保留旧圣遗物后的收益，
并没有把每次都接受新结果的损失放进这个“择优净提升”指标。
这两个问题必须分别看：

- 原始重塑净变化：E[新分数-旧分数]，允许为负。
- 择优保留净提升：E[max(新分数-旧分数,0)]，必定非负。

两种情况都消耗启圣之尘。原始结果不好时可以保留旧圣遗物，资源仍然消耗。

## 充能权重1，双暴和防御权重0

这表示完全只看充能。充能权重设100、其余0也有相同概率，评分数值会同比扩大100倍。
原截图的100:1:1并非完全忽略双暴，充能相同的结果仍会比较双暴。

保底两次表示双暴合计至少强化两次，不表示固定两次双暴后再抽三次。
当前使用末尾补足的社区模型：不足以完成保底时，剩余强化强制进入目标。

由此得到充能强化次数分布：

| 充能强化次数 | 概率 |
|---|---:|
| 0 | 25.000000%（1/4） |
| 1 | 42.187500%（27/64） |
| 2 | 26.562500%（17/64） |
| 3 | 6.250000%（1/16） |

0或1次合计67.1875%，已经少于原来的2次。
同样2次还需要比较成长档位；这件原来的两次充能成长偏高。
例如基础充能6.48时，原两次增加共11.66，新两次至少要增加12.31才能提升充能。
枚举基础值5.18/5.83/6.48及所有四档成长后得到：

| 原始充能结果 | 概率 |
|---|---:|
| 降低 | 86.832682% |
| 相等 | 3.873698% |
| 提高 | 9.293620% |

严格提升概率为571/6144，约9.29%。其中充能强化3次的情况贡献6.25%，
充能强化仍为2次但成长数值更好的情况贡献约3.04%。

如果所有新结果都接受，新充能期望为12.325807292%，
相对两位小数表值18.14%平均下降5.814192708个百分点。
若较差结果保留旧值，最终充能期望为18.441533203%，
平均净增只有0.301533203个百分点。
这说明确实很容易抽坏；保留旧结果让圣遗物不掉分，却不能免除材料消耗。

## 推导及可靠性边界

令双暴命中次数K=max(Binomial(5,1/2),2)。K=2/3/4/5的概率为16/32、10/32、5/32、1/32。
给定K，未命中双暴的5-K次强化在充能与防御之间公平分配。
所以充能命中次数N的概率为：
P(N=n)=Σ_k P(K=k)×C(5-k,n)/2^(5-k)。

对充能成长4.53/5.18/5.83/6.48逐次卷积，按原面板合法分解的基础充能5.18/5.83/6.48
（条件概率1/6、1/3、1/2）分别比较新旧数值；此步骤使用Fraction精确有理数。
独立只看充能的枚举结果与程序内核相符。

独立复算验证的是既定模型内部计算，不是对官方未公开服务器随机算法的直接证明。
如果换成“先固定两次双暴、余下三次四属性均匀抽取”的另一假设，
只看充能的提升概率会变成3.173828%。
这说明保底实现方式确实重要，不能仅凭“至少两次”的官方保证唯一确定所有概率。
