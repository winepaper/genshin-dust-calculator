## 评分与权重

`S = Σ_i w_i × v_i / μ_i`，其中μ为该属性一次成长均值。
均值只用于统一评分单位；概率计算逐次使用四个具体成长档位。
所有正权重都参与当前评分、新评分和差值，与是否勾选为保底无关。
100:1:1是相对价值比例，不是充能命中概率100%。

## 重塑和保底

采用基础值保留、强化落点和成长档位重新抽取的社区模型。
选择两条目标，其合计强化次数至少为g（2、3或4）。
普通阶段四条属性各25%；当剩余强化数等于尚缺的保底数，强制进入所选两条，各50%。

双目标合计命中次数分布等价于 `K=max(Binomial(N,1/2),g)`，其中N为4或5。
这不等价于先固定g次目标强化后，再均匀随机余下次数。
官方保底保证本身不能唯一决定完整概率算法，当前采用的社区分析见文末。

## 未知基础档位

枚举基础档位、强化次数和成长总和，使其符合输入面板的显示舍入，且总强化数为N。
按四档等概率及原始随机强化的先验计算合法状态的条件概率。
每个状态同时保留基础评分和当前评分，避免独立求均值破坏两者相关性。
初始三／四条都可行时使用相同模型先验；条件后验由输入数据决定。

已知强化次数或基础档位可约束枚举。历史择优重塑、人为筛选等会改变先验。
“合法范围”是各合法状态结果的最小／最大值，非置信区间，也非模拟误差。
仅凭满级截图不能唯一还原真实初始值或强化顺序。

## 原始结果与择优保留

设差值D=新评分−当前评分：

| 指标 | 定义 |
|---|---|
| 变好概率 | P(D>0) |
| 原始期望净变化 | E[D]，可能为负 |
| 界面平均净提升 | E[max(D,0)] |
| 每枚尘收益 | E[max(D,0)] / 本次耗尘 |
| 目标达成概率 | P(max(D,0)≥输入目标) |

择优收益把坏结果保留旧值，所以它非负；正收益不代表多数重塑成功。
目标为0时达成概率100%，相等不计“变好”。
花、羽消耗1枚，沙、杯、冠消耗2枚；坏结果保留旧值仍消耗资源。

## 数值实现

权重使用最多三位小数的有理数，成长表转成整数，评分投射到共同整数格点。
内核不合并相邻评分点。动态规划中的路径概率为二进制分数；最终汇总用双精度浮点。
独立核验另用Fraction精确有理数比较关键案例。图表分箱只影响展示。
两位小数表及半入舍入不能完全复现游戏内部浮点边界。
